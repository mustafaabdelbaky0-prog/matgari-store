# متجري — أبليكيشن إدارة متجرك الأونلاين

أبليكيشن ويب بسيط (بيشتغل من المتصفح زي تطبيق موبايل، وممكن "تضيفه للشاشة الرئيسية") لأي حد بيبيع أونلاين ولسه مش عارف يبني لاندنج بيدج أو يحسب مكسبه وبيعه.

## الفكرة

1. التاجر بيسجل حساب ويختار مجاله (ملابس أطفال، عطور، إكسسوارات... إلخ).
2. بيضيف منتجاته (اسم، صورة، سعر شراء، سعر بيع مقترح تلقائيًا، كمية).
3. أي منتج بيضيفه بيظهر أوتوماتيك في صفحة بيع عامة (لاندنج بيدج) بتتولد له لينك خاص بيه يقدر يشاركه مع عملائه.
4. بيسجل مبيعاته ومشترياته، والأبليكيشن بيحدّث المخزون والخزنة (رصيد الفلوس) أوتوماتيك.
5. زرار "اطلب الآن" في صفحة البيع بيودّي العميل لواتساب التاجر مباشرة — مفيش احتياج لبوابة دفع أو شحن معقد، تمامًا زي فكرة إيزي أوردر بس أبسط بكتير.

## مميزات تقنية مهمة

- **صفر مكتبات خارجية (Zero dependencies).** الأبليكيشن اتبنى بالكامل بـ Node.js الأساسي (`http`, `node:sqlite`, `crypto`) عشان تقدر تشغّله فورًا على أي سيرفر من غير `npm install` ومن غير مشاكل تعارض إصدارات.
- قاعدة بيانات SQLite محلية (ملف واحد `data/app.db`) — بسيطة ومناسبة جدًا لبداية مشروعك.
- تصميم عربي (RTL) بالكامل، متجاوب وموبايل-فيرست.
- PWA — يدعم "إضافة للشاشة الرئيسية" فيشتغل بشكل شبه كامل زي تطبيق موبايل حقيقي.

## تشغيله على جهازك

يحتاج فقط [Node.js](https://nodejs.org) الإصدار 20 أو أحدث (يفضل 22+ لأن قاعدة البيانات المدمجة `node:sqlite` مستقرة أكتر فيه).

```bash
node server.js
```

هيفتح على `http://localhost:3000`. افتحه من متصفح الموبايل أو الكمبيوتر وابدأ تسجّل حساب.

> ملحوظة: هتشوف تحذير `ExperimentalWarning: SQLite is an experimental feature` في التيرمينال — ده طبيعي وموجود لأن الميزة دي جديدة في Node، والأبليكيشن شغال بشكل كامل وسليم بيها.

## رفعه أونلاين (استضافة مجانية)

عشان تبعت الرابط لعملائك فعليًا (مش بس على جهازك)، ارفع المشروع على أي خدمة استضافة بتدعم Node.js، زي:

- **Render.com** (فيه خطة مجانية): اعمل New → Web Service، اربطه بمجلد المشروع أو ارفعه على GitHub وحدد Start Command: `node server.js`.
- **Railway.app**: نفس الفكرة، ارفع المشروع وحدد نفس أمر التشغيل.

في كل الحالات مفيش احتياج لأي build step أو npm install لأن المشروع صفر مكتبات.

⚠️ قاعدة البيانات (`data/app.db`) بتتخزن كملف على السيرفر، فلو الاستضافة بتمسح الملفات بعد كل ديبلوي (زي بعض الخطط المجانية) البيانات ممكن تتصفّر. للاستخدام الجدي على المدى الطويل، فكّر في ضبط "Persistent Disk" في إعدادات الاستضافة أو الترقية لقاعدة بيانات خارجية لاحقًا.

## هيكل المشروع

```
server.js          نقطة الدخول والراوتر الرئيسي
lib/db.js          قاعدة البيانات والجداول
lib/auth.js         تسجيل الدخول والجلسات
lib/view.js         قوالب HTML المشتركة
lib/router.js        راوتر بسيط
lib/body.js          قراءة بيانات الفورم
routes/*.js          كل صفحة/قسم في ملف منفصل
public/              CSS، JS، أيقونات، ملف الـ PWA
data/                قاعدة البيانات (بتتعمل تلقائي أول ما تشغّل السيرفر)
```

## نقاط ممكن تتوسع فيها لاحقًا

- تعدد الصور لكل منتج + تصنيفات فرعية.
- تقارير أرباح شهرية ورسوم بيانية.
- دعم أكتر من مستخدم لنفس المتجر (موظفين).
- ربط بوابة دفع أونلاين بدل/بجانب طلب الواتساب.
